# X: texto-svg

Hilo de 1 a 4 posts, cada uno de 280 caracteres como mucho (un enlace cuenta 23, un emoji 2). La imagen va en el
primero. Marca cada post con `**1/**`, `**2/**`… Un hashtag como mucho.

## es

**1/** FLUX no da texto legible, así que el texto no lo pinta el modelo: una plantilla SVG lo pone encima. Cambiar el titular ya no obliga a regenerar. En desarrollo.
Imagen: medios/diagrama.webp

**2/** Se guardan la imagen cruda y la compuesta. Un cambio de titular tras 49 min de generación no puede costar otros 49: componer una pieza lleva ~2 s. #imagenIA
